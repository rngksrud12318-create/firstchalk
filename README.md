# FirstChalk

선생님을 향한 첫걸음, 공부 기록장. 빌드 도구 없이 동작하는 순수 HTML/JS PWA예요.
모든 데이터는 폰 브라우저(IndexedDB)에 저장되고, 서버 비용은 0원이에요.

## 기능

- **홈**: 오늘 공부 시간, 연속 공부 일수, 오늘 할 일, 내일 할 일 안내
- **캘린더**: 월간 달력, 날짜별 할 일, 달력 아래 "내일 할 일은 ~ 입니다" 안내
- **타이머**: 과목별 일반 / 뽀모도로(25분), 일시정지, 종료 시 자동 기록, 화면 켜두기 옵션
- **기록**: 면접 Q&A(질문·답변 붙여넣기, 주제 태그, 검색, 즐겨찾기, 수정), 공부 일지
- **통계**: 최근 7일 그래프, 이번 달·전체 합계, 과목별 시간
- **설정**: 과목 관리, 백업 파일 저장/불러오기

## 내 컴퓨터에서 먼저 열어보기

PWA는 `file://`로는 동작하지 않아서 간단한 서버가 필요해요.

```
cd firstchalk
python3 -m http.server 8000
```

브라우저에서 http://localhost:8000 을 열어요. (Node가 있다면 `npx serve` 도 돼요.)

## 무료 배포 (빌드 설정 없음)

### GitHub Pages
1. GitHub에서 새 저장소를 만들고 이 폴더의 파일을 전부 올려요.
2. 저장소 Settings → Pages → Branch를 `main` / `(root)`로 선택해요.
3. 몇 분 뒤 `https://내아이디.github.io/저장소이름/` 주소로 열려요.

### Cloudflare Pages
1. Workers & Pages → Create → Pages에서 저장소를 연결하거나 폴더를 직접 업로드해요.
2. 빌드 명령은 비우고, 출력 디렉터리도 비워두면 돼요.

## 안드로이드에 설치하기

1. 폰 크롬으로 배포 주소를 열어요.
2. 메뉴(⋮) → **홈 화면에 추가** 또는 **앱 설치**를 눌러요.
3. 이후에는 앱처럼 실행되고 오프라인에서도 열려요.

## 수정해서 다시 배포할 때

`sw.js` 맨 위의 `VERSION` 숫자를 올려 주세요(예: `firstchalk-v2`). 올리지 않으면 폰에 예전 파일이 캐시된 채 남을 수 있어요.

## 데이터 백업

데이터는 그 폰의 브라우저 안에만 있어요. 앱 삭제나 사이트 데이터 삭제 시 사라질 수 있으니
**설정 → 백업 파일 저장**으로 가끔 내려받아 두세요. 새 폰이나 다른 주소로 옮길 때는 **백업 불러오기**로 복원해요.
